# StumbleScience

A lightweight, StumbleUpon-inspired discovery tool for exploring open-access science resources.

## Features
- **Topic Filtering:** Browse across curated categories or stumble through all subjects at once.
- **Framed Viewer:** Full-screen embedded browsing with a quick fallback link for sites with strict frame headers.
- **Wikipedia Lookup:** Built-in split-screen panel for quick concept and terminology searches.
- **Themes:** Light, Dark, and Sepia modes.
- **Easy Expansion:** All topics and URLs are managed in a single dictionary inside `data.js`.
